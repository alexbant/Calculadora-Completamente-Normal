## Proyecto para un video meme

Un proyecto no tan serio pero lo armé como la típica calculadora con algo un poquito especial.
Uso se atributos básicos como articles, divs y spans.

Colores pastel suave entre blanco y morado, uso de border-radius para botones; y por su puesto, la interfaz de micropagos cuando se apriete el signo "=".


### JavaScript

#### Funciones básicas

- Las que enseñan en colegio sobre el cálculo de operaciones.
- Al ser de broma no realiza ninguna operación de verdad.

#### Funciones especiales

- Al darle al símbolo de "=" cuando no hay ninguna operación o número en la entrada no calcula nada.
- Cuando quieres pagar (de **broma** obviamente) suelta un mensaje de que el plan todavía no acepta pagos.

- Más aparte de todo, este código está abierto a todo el mundo para que lo puedan modificar a su gusto y lo desarrollen.
